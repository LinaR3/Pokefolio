# 🎮 Pokéfolio - Lina Reina

Portafolio interactivo con estética GameBoy 2D / Pokédex y pantalla de bienvenida estilo editorial moderno.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Grid & Custom Properties)
- JavaScript Vanilla ES Modules (ó Vite / React)
- Google Fonts (`Inter` & `Press Start 2P`)

## 🚀 Inicio Rápido
1. Clona este repositorio.
2. Abre `index.html` en tu navegador (o ejecuta `npx serve .`).
